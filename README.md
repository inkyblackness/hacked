# Inky Blackness HackEd 2

[HackEd](https://github.com/inkyblackness/hacked) is the main graphical editor application as part of the
[Inky Blackness](https://inkyblackness.github.io) project. It allows editing the game files of the original System Shock
(1994 and compatible) to create mods and fan-missions.

This application is the successor of the `deck` package of Inky Blackness, which provided the first public editor, even
before the source release of the original engine.

> At least, this is what this branch is set out to be. If you found this branch before any meaningful release,
> congratulations :) - it probably won't work as intended. Yet.
>
> This branch is one of those cases where, as a developer, I was fed up with the previous thing (also, years passed),
> and I wanted a new hobby project to focus on. HackEd 2 is a rewrite from the ground up. Experiences from the previous
> releases flow into it, together with a new architecture and different programming language, to now focus on the user
> experience first.
>
> The previous iterations where always focused on the data files; Inky Blackness originally came out of reverse
> engineering and documenting the data files. The resulting tools were rather focused on them before a good experience.
